# Horror Stories by ManyMotions

Turn a scary story idea into a narrated horror, paranormal, creepypasta or suspense short for faceless YouTube, TikTok and Shorts channels, delivered as an MP4 from your ManyMotions account.

## Install

1. Open **Cursor Settings → Plugins**.
2. Search for **Horror Stories by ManyMotions**.
3. Click **Install**, then sign in to ManyMotions when Cursor asks.

Or run `/add-plugin manymotions-horror-story-video` in chat.

## MCP

```json
{
  "mcpServers": {
    "manymotions-horror-story-video": {
      "type": "http",
      "url": "https://manymotions.com/api/grok/horror-story-video/mcp"
    }
  }
}
```

Auth is OAuth 2.1 with PKCE against ManyMotions. Cursor opens the ManyMotions sign-in when the plugin connects.
