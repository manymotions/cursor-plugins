# ManyMotions plugins for Cursor

Plugins that connect Cursor agents to [ManyMotions](https://manymotions.com) through its remote MCP servers: AI video and image generation, logo concepts and UGC video ads. Each plugin is an MCP server plus a skill that tells the agent how to use its tools.

| Plugin | Name | MCP server |
|---|---|---|
| [AI Video Generator by ManyMotions](manymotions-video-generation/) | `manymotions-video-generation` | `https://manymotions.com/api/grok/mcp` |
| [AI Image Generator by ManyMotions](manymotions-image-generation/) | `manymotions-image-generation` | `https://manymotions.com/api/grok/mcp` |
| [AI Video & Image Maker by ManyMotions](manymotions-video-image-generation/) | `manymotions-video-image-generation` | `https://manymotions.com/api/grok/mcp` |
| [AI Logo Maker by ManyMotions](manymotions-logo-maker/) | `manymotions-logo-maker` | `https://manymotions.com/api/grok/logomaker/mcp` |
| [AI UGC Video Ads by ManyMotions](manymotions-ugc-video-ads/) | `manymotions-ugc-video-ads` | `https://manymotions.com/api/grok/ugc/mcp` |

## Install

Open **Cursor Settings → Plugins**, search for the plugin and click **Install**, then sign in to ManyMotions when Cursor asks (OAuth 2.1 with PKCE). Each plugin's README has its MCP block and example prompts.

## Pricing

The plugin is free. Generations use credits from your ManyMotions account. Plans begin with a $1, 3-day trial, then cost $29/month (Starter, 4,500 credits), $42/month (Pro, 10,000 credits) or $109/month (Agency, 30,000 credits). Preparing is free and shows the exact credits before anything is spent.
