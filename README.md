# ManyMotions plugins for Cursor

Plugins that connect Cursor agents to [ManyMotions](https://manymotions.com) through its remote MCP servers: AI video and image generation, logo concepts, UGC video ads, single-purpose video, voiceover and moodboard makers, and a timeline video editor. Each plugin is an MCP server plus a skill that tells the agent how to use its tools.

## Install

Open **Cursor Settings → Plugins**, search for the plugin and click **Install**, then sign in to ManyMotions when Cursor asks (OAuth 2.1 with PKCE). Each plugin's README has its MCP block and example prompts.

## Pricing

The plugin is free. Generations use credits from your ManyMotions account. Plans begin with a 7-day trial for $1 + tax, then cost $29/month + tax (Starter, 4,500 credits), $42/month + tax (Pro, 10,000 credits) or $109/month + tax (Agency, 30,000 credits). Preparing is free and shows the exact credits before anything is spent.
